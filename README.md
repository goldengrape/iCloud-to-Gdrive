# iCloud 到 Google Drive 迁移工具项目文档

本目录由 Vibe Coding Skill 的文档结构整理而来，用于在开始编码前固定项目范围、模块边界、测试口径和实现顺序。

本包只包含项目文档与 AI 检索 wiki，不包含产品代码。

## 目录

- `docs/URD.md`：用户需求文档，定义目标、范围、约束和验收标准。
- `docs/ADD.md`：设计拆分文档，定义功能需求、设计参数和耦合关系。
- `docs/MDD.md`：模块设计文档，定义模块、接口、数据结构和契约。
- `docs/TDD.md`：测试计划文档，定义测试用例和判定依据。
- `docs/RMD.md`：开发路线文档，定义实现顺序、停止条件和 Git 检查点。
- `docs/TRACE.md`：需求、设计、模块、测试、任务和 wiki 的追踪表。
- `wiki/`：给 AI 检索用的短笔记，不新增需求。
- `.vibe/`：机器可读的追踪状态。

## 文档强度

本项目按 strict 级别整理。原因：项目涉及本地隐私数据、OAuth 权限、文件完整性、迁移证据，以及可能导致用户误删 iCloud 数据的清理指引。

## 当前结论

MVP 只做本地读取、上传、校验和手动清理指引。不会收集 Apple ID 密码，不调用自动删除接口，不清空“最近删除”或废纸篓。
